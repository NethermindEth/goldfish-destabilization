# Explainers

Textbooks that explain each protocol from the ground up, for a reader who knows Ethereum's
consensus but not these proposals. Each is written in Typst, with figures generated by a Python
script, and ships its compiled PDF. Each folder's README has the chapter list and the build
commands.

| Folder | Protocol | Contents |
|---|---|---|
| `goldilocks/` | Goldilocks: Goldfish with locks, composed with a finality gadget (FGSA spec of 22 Oct 2026) | `goldilocks-textbook.pdf`, one Typst file per chapter: why the protocol changed, the model, the finality gadget (heights, attestations, client), the FG frame (fork-choice root, viable heads, contests), Goldfish votes and the head walk, confirmation and locks, restart, the healing argument, the first experiments with `../simulator/goldilocks/`, and open questions. `generate_figures.py` runs the simulator for some of its figures |
| `goldfish-simplex/` | Goldfish + stabilization gadget + Simplex finality (`fradamt/consensus-specs@simplex-healing`) | `decoupled-consensus-textbook.pdf`: a progressive course on the first proposal, with worked examples and recaps, in dependency order |
