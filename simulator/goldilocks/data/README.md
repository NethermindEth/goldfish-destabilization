# Data of the Goldilocks experiments

Everything here is generated by seeded runs of the simulator in `..`. Rebuild with
`bash build_explorer.sh` (`runs/`) and `bash reproduce.sh` (`batches/`), from `simulator/goldilocks/`.

## `runs/`: the explorer tabs

One run per tab of `../explorer/goldilocks-explorer.html`: `<name>.events.json` (every message
and the per-slot state of every node, what the explorer draws) and `<name>.json` (the run's
summary: orphaned confirmations, finality timeline, invariant checks, the adversary's notes).
`build_explorer.sh` lists the command of each run. `index.json` is the partition study's index.

## `batches/`: the numbers of the report

`*.json` files come from `fuzz_batch.py`: one entry per proposer schedule (seed), with its
`argv`. They are stored with Git LFS: install `git-lfs` before cloning, or run `git lfs pull`
after (without it they are small pointer files). `python summarize.py batches/*.json` gives the counts below (`batches/summary.txt`).
"Attacked" = the schedule gave the adversary the slots it needs; "succeeded" = an honest node
showed B as confirmed and B was orphaned. The `.txt` files are the output of the drivers that only
print. Section numbers refer to `reports/goldilocks-finalization-hiding/finalization_hiding.pdf`.
